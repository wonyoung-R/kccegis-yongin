음성 검증은 음성 트랙·브라우저 디코딩·재생 및 음소거 상태를 확인한 것입니다. 사용자 기기의 스피커 출력과 음량은 별도 환경에 따릅니다. 첫 방문에는 브라우저 자동 재생 정책에 따라 음소거이며, **소리 ON** 버튼을 누르면 소리가 켜집니다. 버튼에는 누르면 실행되는 동작을 표시합니다.

탭 전환과 스크롤 정지 상태가 겹치면 자동 재생이 복구되지 않던 문제를 수정했습니다. 추가 상태 전이 검증 8건을 통과했습니다: 화면 밖·탭 전환 후 복귀, 수동 정지 보존, 모션 축소 초기/변경/수동 재생, AbortError, 자동 재생 거부, 영상 오류.

세로 영상의 자막을 보여주기 위해 중앙 영상 크롭을 줄이고, 넓은 화면 가장자리는 같은 영상의 포스터를 흐리게 채웠습니다. 첫 장면과 12초·26초 장면에서 자막 위치를 확인했습니다. 영상 안에 이미 들어 있는 자막 글꼴은 원본 그대로입니다.

## 하단 채널·오시는 길 수정

인스타그램 `kccegis_junior_yongin`과 블로그 `kcc_junior_yongin`은 [센터가 공개한 업체 프로필](https://www.daangn.com/kr/local-profile/kcc%EC%9D%B4%EC%A7%80%EC%8A%A4%EC%A3%BC%EB%8B%88%EC%96%B4-%EB%86%8D%EA%B5%AC%EA%B5%90%EC%8B%A4-cpeoyewaakjd/)에서 확인했습니다. 블로그 홈의 제목도 KCC이지스 주니어 용인점으로 확인했습니다. SNS는 로고만 표시하고 접근성 이름을 제공하며, 지도와 함께 새 창으로 열립니다. 요청한 자료 출처·운영 확인 푸터 문구 두 줄은 제거했습니다.

이전 `browser-validation.json`의 외부 링크 0개는 SNS 추가 전 검증 기록입니다. 이번 변경의 외부 링크 3개는 `npm run check`에서 주소·새 창 속성을 검사합니다.

하단 변경 후 360·390·768·1440·1977px에서 가로 넘침 0, 44px 미만 링크 0, 로고 로딩과 두 문구 제거를 확인했습니다. 외부 링크는 허용 주소·`target="_blank"`·`rel="noopener noreferrer"`를 검사했습니다. 자동화 브라우저의 탭 목록에는 팝업이 등록되지 않아 외부 사이트의 새 탭 렌더링까지 확인한 결과는 아닙니다.
