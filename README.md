# KCC 이지스 주니어 용인점 홈페이지

센터 사진·영상과 스크롤 연출을 사용하는 반응형 홈페이지입니다. HTML, CSS, JavaScript와 미디어를 독립 파일로 관리합니다. 데이터베이스나 빌드용 외부 패키지는 사용하지 않습니다.

## 로컬에서 실행

설치되어 있는 Node.js/npm과 Python 3를 사용합니다. `npm install`은 필요하지 않습니다.

```sh
npm run dev
```

브라우저에서 **http://localhost:5173** 을 엽니다. 파일을 수정하고 브라우저를 새로고침하면 반영됩니다. 서버 종료는 터미널에서 `Ctrl+C`입니다.

## 구조와 수정 위치

```text
index.html              페이지 구조, 소개, 시간표, 교육비, 연락처
css/style.css           색상, 레이아웃, 반응형 화면, 전환 효과
js/main.js              메뉴, 영상 재생·음소거, 패널, 시간표, 스크롤 동작
assets/images/          실제 사용하는 센터 사진, 로고, 시간표 원본
assets/videos/          Hero 영상
assets/fonts/           내장 글꼴과 라이선스
scripts/                파일 검증 및 배포 폴더 생성
docs/                   이미지 목록과 검증 기록
dist/                   npm run build로 생성되는 배포 파일
```

시간표는 `index.html`의 `#schedule`, 교육비는 `#fees`, 주소·전화번호는 `#contact`에서 수정합니다. 사진을 교체할 때는 `assets/images/`에 넣고 해당 `img`의 `src`와 `alt`를 바꿉니다. 사용 사진 목록은 `docs/assets.json`에 있습니다.

## 검증 및 배포 파일 생성

```sh
npm run check
npm run build
npm run preview
```

빌드된 홈페이지는 **http://localhost:4173** 에서 확인합니다. 정적 호스팅에는 **`dist/` 안의 파일과 폴더를 함께** 올립니다. 빌드 명령은 `npm run build`, 게시 디렉터리는 `dist`입니다. 서버 함수·환경 변수·외부 CDN은 필요하지 않습니다. 저장소 전체나 `index.html` 하나만 올리지 마세요.

`dist/`는 소스에서 복사한 결과입니다. 수정은 루트의 원본 파일에서 하고 다시 빌드합니다. 빌드 명령은 기존 파일을 삭제하지 않으므로, 이후 소스에서 파일명을 바꾼 경우 배포 폴더의 오래된 파일도 함께 확인하세요.

공유 URL은 호스팅에 게시한 뒤 생깁니다. 현재 프로젝트에는 특정 호스팅 계정·도메인을 연결하지 않았습니다.

## 현재 안내에서 확인이 필요한 사항

- 토요일 중등부 대표팀: 원본 시간 칸은 19:30–21:30, 셀 내부는 20:30–22:00으로 달라 센터 확인이 필요합니다.
- 대표팀의 결제 주기와 총액, 의류 가격·유니폼 지원의 현재 적용 여부는 등록 또는 주문 전 확인하도록 표시했습니다.
- 시간표는 제공된 기존 원본 기준입니다. 최신 시간표로 임의 변경하지 않았습니다.

## 자료와 접근성

사진·영상·로고는 제공된 `../images/` 자료를 사용해 웹용으로 최적화했습니다. 상위 `images` 폴더나 이전 단일 HTML에 실행을 의존하지 않습니다. 원본 자료는 보존했습니다.

모바일 문의 버튼, 전체 화면 메뉴, 키보드 패널 선택, 영상 일시정지·소리 켜기/끄기, `prefers-reduced-motion`을 지원합니다. Barlow Condensed 글꼴의 라이선스는 `assets/fonts/OFL.txt`에 포함되어 있습니다.

한글은 로컬 Pretendard Variable(본문 500, 제목 600 이상)을 사용합니다. 라이선스는 `assets/fonts/Pretendard-LICENSE.txt`입니다. 영문 디스플레이 제목은 Barlow Condensed를 유지합니다.

영상은 제공된 원본의 AAC 음성을 포함합니다. 브라우저의 자동 재생 정책에 맞춰 처음에는 음소거로 재생하며, 오른쪽 상단의 **소리 ON** 버튼을 누르면 소리가 켜집니다. 버튼에는 누르면 실행되는 동작을 표시합니다. 일시정지 버튼과 소리 버튼은 투명한 배경으로 나란히 배치했습니다. 세로 영상의 코치와 내장 자막이 함께 보이도록 크롭하고, 넓은 화면의 여백에는 같은 영상의 포스터를 흐리게 배치했습니다. 영상에 이미 들어 있는 자막 글꼴은 원본 그대로입니다.

실제 화면과 검증 결과는 [docs/validation.md](docs/validation.md)에 정리했습니다.

하단 SNS 로고는 인스타그램 `kccegis_junior_yongin`, 네이버 블로그 `kcc_junior_yongin`으로 연결됩니다. 오시는 길에는 센터 주소와 네이버 지도 검색 링크를 표시합니다. 요청된 외부 링크 3개는 새 창으로 열립니다. 링크를 변경할 때는 `index.html`과 `scripts/check.mjs`의 허용 주소를 함께 변경하세요.
